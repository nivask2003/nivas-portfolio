Nivas Kumar S — Portfolio Website
==================================

This is a standalone static portfolio website.

To view locally:
  1. Unzip the archive.
  2. Open index.html in any modern web browser.

To host online:
  - Upload the entire folder contents to any static web host
    (Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.).

Included files:
  - index.html
  - css/style.css
  - js/script.js
  - images/
  - assets/Nivas_Kumar_Resume.pdf

External CDN dependencies (require internet):
  - Bootstrap 5 CSS/JS
  - AOS animation library
  - Google Fonts
